# Task 1: Exploration and Visualization of Simple Dataset of IRIS


## Objective

To perform exploratory data analysis (EDA) on the Iris dataset and visualize feature distributions, relationships, and outliers using Python.

## Dataset

* Iris Dataset
* 150 observations
* 4 numerical features
* 3 species classes:

  * Setosa
  * Versicolor
  * Virginica

## Tools and Libraries

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-Learn

## Visualizations Performed

1. Scatter Plot
2. Histograms
3. Box Plots

## Key Findings

* Petal measurements are highly useful for species classification.
* Setosa is clearly distinguishable from other species.
* Dataset contains very few outliers.
* No missing values were found.

## Key Results and Findings

The Iris dataset is well-structured and ideal for learning data exploration and visualization techniques. The analysis demonstrates how visualization can uncover patterns and relationships in data.
